# Лабораторная работа №2

## Объектно-ориентированное программирование

В примере реализована модель игровых объектов с использованием наследования и абстрактных базовых классов.

- `GameObject` — базовый игровой объект с идентификатором, именем и координатами.
- `Unit` — объект с запасом здоровья и получением урона.
- `Attacker` и `Moveable` — абстрактные интерфейсы атаки и перемещения.
- `Archer`, `Fort`, `MobileHouse` — конкретные игровые объекты.
