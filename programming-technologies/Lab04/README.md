# Лабораторная работа №4 — Поведенческие паттерны проектирования

## Цель работы

Изучить и реализовать на Python три поведенческих паттерна проектирования: **Strategy**, **Chain of Responsibility** и **Iterator**.

## Структура проекта

```text
Lab04/
├── README.md
├── strategy.py
├── chain_of_responsibility.py
└── iterator.py
```

## 1. Strategy (Стратегия)

**Назначение:** определяет семейство взаимозаменяемых алгоритмов и позволяет выбирать алгоритм во время выполнения программы.

**Пример:** заказ оплачивается картой или наличными. Класс `Order` делегирует оплату выбранной стратегии.

**Запуск:**

```bash
python strategy.py
```

**Результат:**

```text
Оплата картой: 1000 руб.
Оплата наличными: 500 руб.
```

## 2. Chain of Responsibility (Цепочка обязанностей)

**Назначение:** передаёт запрос последовательно между обработчиками, пока один из них не обработает запрос или цепочка не закончится.

**Пример:** менеджер одобряет суммы до 1000 рублей, директор — до 10000 рублей. Более крупные запросы остаются без обработки.

**Запуск:**

```bash
python chain_of_responsibility.py
```

**Результат:**

```text
Менеджер одобрил запрос
Директор одобрил запрос
Запрос не обработан
```

## 3. Iterator (Итератор)

**Назначение:** предоставляет последовательный доступ к элементам коллекции без раскрытия деталей её обхода.

**Пример:** коллекция книг `BookCollection` возвращает собственный итератор `BookIterator`, который реализует методы `__iter__()` и `__next__()`.

**Запуск:**

```bash
python iterator.py
```

**Результат:**

```text
Python
Алгоритмы
ООП
```

## Запуск всех примеров

Из папки `Lab04`:

```bash
python strategy.py
python chain_of_responsibility.py
python iterator.py
```

Сторонние библиотеки не требуются.

## Вывод

В ходе лабораторной работы реализованы три поведенческих паттерна. Стратегия позволяет менять алгоритм без изменения клиентского кода; цепочка обязанностей разделяет обработку запросов между несколькими объектами; итератор обеспечивает последовательный обход коллекции через единый интерфейс.
