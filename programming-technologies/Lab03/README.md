# Лабораторная работа №3

## Порождающие паттерны проектирования

**Цель работы:** изучить порождающие паттерны проектирования и реализовать их на языке Python.

## Реализованные паттерны

| Паттерн | Файл | Назначение |
| --- | --- | --- |
| Singleton (Одиночка) | `singleton.py` | Обеспечивает один экземпляр класса |
| Factory Method (Фабричный метод) | `factory_method.py` | Передаёт создание конкретного объекта подклассу фабрики |
| Abstract Factory (Абстрактная фабрика) | `abstract_factory.py` | Создаёт семейства связанных объектов |
| Builder (Строитель) | `builder.py` | Собирает объект пошагово |

## Описание реализаций

### 1. Singleton

Класс `Settings` сохраняет единственный экземпляр в атрибуте `_instance`. Метод `__new__` создаёт объект только при первом обращении. Проверка `first is second` возвращает `True`.

### 2. Factory Method

Базовый класс `TransportFactory` определяет фабричный метод `create_transport()`. Подклассы `CarFactory` и `BikeFactory` создают соответственно `Car` и `Bike`.

### 3. Abstract Factory

`FurnitureFactory` определяет методы создания стула и стола. `ModernFactory` создаёт современную мебель, а `ClassicFactory` — классическую. Объекты одного семейства создаются согласованно.

### 4. Builder

`ComputerBuilder` поэтапно задаёт процессор и оперативную память компьютера. Методы `set_cpu()` и `set_ram()` возвращают `self`, позволяя объединять вызовы в цепочку. Метод `build()` возвращает собранный компьютер.

## Запуск

Требуется Python 3. Сторонние библиотеки не используются.

Из корня репозитория:

```bash
python Lab03/singleton.py
python Lab03/factory_method.py
python Lab03/abstract_factory.py
python Lab03/builder.py
```
