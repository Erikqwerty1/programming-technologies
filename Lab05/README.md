# Лабораторная работа №5 — Структурные паттерны проектирования

**Язык:** Python 3. Сторонние библиотеки не требуются.

## Цель работы

Изучить и реализовать структурные паттерны **Proxy**, **Bridge** и **Adapter**.

## Реализованные паттерны

| Паттерн | Файл | Пример | Назначение |
|---|---|---|---|
| Proxy (Прокси) | [`proxy.py`](proxy.py) | Доступ к документу | Контролирует обращение к настоящему объекту |
| Bridge (Мост) | [`bridge.py`](bridge.py) | Пульт и устройства | Разделяет управление и реализацию устройства |
| Adapter (Адаптер) | [`adapter.py`](adapter.py) | Старый принтер | Преобразует несовместимый интерфейс в ожидаемый |

## Запуск

Из корня репозитория:

```bash
python Lab05/proxy.py
python Lab05/bridge.py
python Lab05/adapter.py
```

## Результаты выполнения

**Proxy:**

```text
Доступ запрещён
Содержимое документа
```

**Bridge:**

```text
Телевизор включён
Радио включено
```

**Adapter:**

```text
Старый принтер: Привет, мир!
```

## Вывод

Реализованы три структурных паттерна: Proxy ограничивает доступ к объекту, Bridge позволяет независимо менять устройство и управление, Adapter согласует несовместимые интерфейсы.
